# HFUT-PerceptPulse 前端应用 (Frontend)

基于 **Vue 3 + Vite + Element Plus + Axios** 构建的合肥工业大学校园学术与竞赛情报感知系统看板。

## 特色功能

- **双校区/全校区一键过滤**：支持翡翠湖校区、屯溪路校区、宣城校区及线上学术活动的快速切换。
- **情报多维分类与模糊检索**：按学术讲座、竞赛选拔、双创活动及关键词检索。
- **⭐ 竞赛与讲座关注/收藏（本地持久化）**：
  - 每张卡片右上角设有五角星收藏按钮（★/☆），点击即可加入“我的关注”。
  - 自动通过 `localStorage` 存储，无需登录即可持久保存个人关注列表。
  - 筛选栏集成 **“⭐ 我的关注”** 专属 Tab 及关注数量角标，一键聚合已关注事项。
- **📅 加入系统日历 (.ics 导出与提醒)**：
  - 点击卡片或详情页中的 **“📅 日程”** 按钮，系统将动态生成符合 **RFC 5545** 标准的 `.ics` 日历事件文件并下载。
  - 内置两道到期闹钟提醒规则（提前 1 天日常提醒 + 提前 2 小时紧急提醒）。
  - 双击生成的 `.ics` 文件，即可直接导入 **iOS 日历、Mac 日历、Windows Outlook、安卓各大手机日历**，并自动关联原文链接与地点。
- **截止时间动态预警倒计时**：
  - 距截止 <= 3 天：🔥 红色高亮脉冲警示
  - 距截止 4~7 天：⚡ 橙色预警
  - 常规进行 / 已截止状态智能计算
- **卡片式情报流（Card Grid）**：展示标题、主办学院、地点、摘要、主题标签与热度浏览量。
- **情报详情弹窗**：支持查看通知完整正文，并一键跳转至校园网原文。
- **📡 联网感知采集快捷键**：前端一键触发后端实时爬虫抓取最新公告。

## 本地启动

```bash
# 1. 进入前端目录
cd frontend

# 2. 启动 Vite 开发服务器 (默认运行在 5173 端口)
npm run dev
```

开发服务器已配置反向代理：所有 `/api` 请求将自动转发至后端 `http://127.0.0.1:8000`。
