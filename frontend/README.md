# HFUT-PerceptPulse 前端应用 (Frontend)

基于 **Vue 3 + Vite + Element Plus + Axios** 构建的合肥工业大学校园学术与竞赛情报感知系统看板。

## 特色功能

- **双校区/全校区一键过滤**：支持翡翠湖校区、屯溪路校区、宣城校区及线上学术活动的快速切换。
- **情报多维分类与模糊检索**：按学术讲座、竞赛选拔、双创活动及关键词检索。
- **截止时间动态预警倒计时**：
  - 距截止 <= 3 天：🔥 红色高亮脉冲警示
  - 距截止 4~7 天：⚡ 橙色预警
  - 常规进行 / 已截止状态智能计算
- **卡片式情报流（Card Grid）**：展示标题、主办学院、地点、摘要、主题标签与热度浏览量。
- **情报详情弹窗**：支持查看通知完整正文，并一键跳转至校园网原文。

## 本地启动

```bash
# 1. 进入前端目录
cd frontend

# 2. 启动 Vite 开发服务器 (默认运行在 5173 端口)
npm run dev
```

开发服务器已配置反向代理：所有 `/api` 请求将自动转发至后端 `http://127.0.0.1:8000`。
